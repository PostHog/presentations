The shift

Self-driving = discovery + delivery

Agents are now working on the discovery side of the product loop.

Discovery
Feedback in, insight out
Agents ingest feedback, conduct research, and draft the specs.
feedback · research · specs
supervised by PMs
→
Delivery
Spec in, software out
Agents write the code, open the PRs, run the tests.
code · PRs · tests · deploys
supervised by engineers

Step 2 · Evals

Same trace, two evals

The vague one lets it pass. The sharp one catches the missed use case.

✕ Vague eval · accuracy
Rubric"Was the response accurate?"

✓ Sharp eval · answer completeness
Rubric"Was the user's question fully answered?"
ResultFail — flagged: question unanswered
The gap becomes a signal. user questions only · 25% sample

Takeaways

What to take home

  • Agents are getting good at discovery — good enough to make self-driving possible.
  • Engineers supervise delivery agents; PMs supervise discovery agents.
  • PMs create agentic discovery by building the high-quality context pipelines: sources, evals, signals.
